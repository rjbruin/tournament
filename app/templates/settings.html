OpenRouter (Ask AI)

The "Ask AI" chat page uses OpenRouter to query a language model with tool access to your simulation results. Your API key is stored with your account and never sent anywhere except to OpenRouter.

The shared key is paid for and rate-limited by the admin and is used by everyone who selects it — expect occasional "out of credits" or rate-limit messages during busy periods. If you have your own OpenRouter account, using your own key is more reliable.
Any model slug available on OpenRouter, e.g. anthropic/claude-sonnet-4.5, openai/gpt-4o.
Simulation
Used as the default for new runs (100 - 500,000). Higher values take longer to compute.

Scenarios

Scenarios are managed automatically — there's one for each state of the tournament (before the first match, then after every match played). You normally don't need to touch them; use "Update results" on the Home page to pull in the latest official results. This panel is here if you want to inspect, compare, or create "what if" scenarios.
